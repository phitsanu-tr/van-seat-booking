# van-seat-booking

เว็บจองที่นั่งรถตู้ 10 ที่นั่ง แตะที่นั่งในผัง ใส่ชื่อ แล้วกด OK ทุกคนที่เปิดลิงก์เห็นรายชื่อชุดเดียวกัน ไม่ต้องล็อกอิน ใช้เปิดผ่านไลน์ได้

- `index.html` หน้าเว็บ (ไฟล์เดียว ไม่ต้อง build)
- `admin.html` หน้าสร้าง/แก้ไขทริป (ชื่อทริป เพจ วันที่ เวลารถออก นัดพบ จำนวนรถ)
- `api/seats.js` จองและยกเลิกที่นั่ง, `api/trip.js` สร้าง/แก้ทริป, `api/_lib.js` ตัวช่วยร่วม (เก็บข้อมูลลง Upstash Redis)

## หลายทริป หลายคัน

- เปิด `/admin.html` กรอกรายละเอียด เลือกจำนวนรถ แล้วกดสร้าง จะได้ 2 ลิงก์
  - ลิงก์ผู้จอง `/รหัสทริป` (8 ตัว) ส่งเข้ากลุ่ม
  - ลิงก์แก้ไข `/a#รหัสทริป-รหัสลับ` (รหัสลับ 16 ตัว) เก็บไว้เองคนเดียว (ไม่มีล็อกอิน ใครมีลิงก์นี้แก้ทริปได้) ส่วนหลัง `#` เบราว์เซอร์ไม่ส่งไปเซิร์ฟเวอร์ จึงไม่ติด log และบอตสแกนลิงก์ไม่เห็น
  - เซิร์ฟเวอร์เก็บแค่ค่าแฮช SHA-256 ของรหัสลับ, ใส่รหัสผิดเกิน 10 ครั้ง/ชม./IP จะถูกบล็อก, หน้าแอดมินใส่ noindex
  - ลิงก์แบบเก่า `/?t=รหัส` และ `/admin.html?t=รหัส&k=รหัสลับ` ยังใช้ได้
  - สร้างทริปได้ 5 ทริป/เดือน/เบราว์เซอร์ (เพดาน 15 ทริป/เดือน/IP)
- ลิงก์เดิมที่ไม่มี `?t=` ยังใช้ได้ และข้อมูลเก่าไม่หาย (เป็นทริป `default` คัน A)

## วิธีติดตั้ง

1. เข้า vercel.com → Add New → Project → import repo นี้ ตั้ง Framework Preset เป็น **Other** ปล่อย Build Command ว่างไว้
2. ในโปรเจกต์ ไปที่ Storage → เพิ่ม **Upstash for Redis** แล้วเชื่อมเข้ากับโปรเจกต์ ระบบจะใส่ตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง (ถ้ากำหนด prefix ไว้ เช่น `VAN_SEAT_BOOKING_` ก็อ่านได้)
3. กด Redeploy เพื่อให้ตัวแปรมีผล

## วิธีใช้

- แตะที่นั่งว่าง → ใส่ชื่อ → OK
- แตะที่นั่งที่มีชื่อแล้ว → "ยกเลิกการจอง" → ยืนยัน (ใครก็ยกเลิกได้ มีขั้นยืนยันกันเผลอกด)
- ที่นั่งที่จองจากเครื่องนี้จะเป็นสีเขียวน้ำเงิน (เครื่องจำไว้แค่เพื่อแต่งสี ไม่ได้ใช้เป็นสิทธิ์)
- ผังอัปเดตเองทุก 8 วินาทีขณะเปิดหน้า

## ข้อมูลที่เก็บ

ทริป: `trip:<รหัส>` (JSON). ชื่อผู้จองและเวลาจอง: hash `seats:<ทริป>:<คัน>` (ทริปเดิมคัน A ยังใช้ `van:seats`)

เดิมเก็บใน Redis hash `van:seats` สองคนกดที่นั่งเดียวกันพร้อมกัน ระบบรับคนแรกคนเดียว (`HSETNX`)
