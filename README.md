# van-seat-booking

เว็บจองที่นั่งรถตู้ 10 ที่นั่ง กดที่นั่งในผัง ใส่ชื่อและ PIN 4 หลัก แล้วกด OK ทุกคนที่เปิดลิงก์เห็นรายชื่อชุดเดียวกัน ไม่ต้องล็อกอิน

- `index.html` หน้าเว็บ (ไฟล์เดียว ไม่ต้อง build)
- `api/seats.js` ฟังก์ชันของ Vercel เก็บข้อมูลลง Upstash Redis

## วิธีติดตั้ง

1. เข้า vercel.com → Add New → Project → import repo นี้ ตั้ง Framework Preset เป็น **Other** ปล่อย Build Command ว่างไว้
2. ในโปรเจกต์ที่สร้างแล้ว ไปที่ Storage (หรือ Marketplace) → เพิ่ม **Upstash for Redis** แล้วเชื่อมเข้ากับโปรเจกต์ ระบบจะใส่ `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง
3. ไปที่ Settings → Environment Variables เพิ่ม `ADMIN_CODE` เป็นรหัสแอดมินของคุณ (ไว้ยกเลิกการจองแทนทุกคน)
4. กด Redeploy เพื่อให้ตัวแปรมีผล

ถ้าใช้ฐานข้อมูล Upstash ที่สร้างเองนอก Vercel ให้ตั้ง `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` แทน

## วิธีใช้

- แตะที่นั่งว่าง → ใส่ชื่อ และ PIN 4 หลักสำหรับยกเลิกภายหลัง → OK
- ยกเลิกการจอง: แตะที่นั่งของตัวเอง (เครื่องที่จองจะจำ PIN ไว้ให้) หรือใส่ PIN ที่ตั้งไว้ถ้าใช้เครื่องอื่น
- แอดมินใส่ `ADMIN_CODE` ในช่อง PIN เพื่อยกเลิกที่นั่งของใครก็ได้
- ใส่ PIN ผิดเกิน 8 ครั้งต่อที่นั่ง จะถูกล็อก 10 นาที

## ข้อมูลที่เก็บ

ชื่อผู้จองและเวลาจอง เก็บใน Redis hash `van:seats` โดย PIN เก็บเป็น hash ไม่เก็บตัวเลขจริง
