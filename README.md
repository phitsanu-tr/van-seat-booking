# van-seat-booking

เว็บจองที่นั่งรถตู้ (คันละ 10 ที่นั่ง) ผู้จัดสร้างทริปแล้วแชร์ลิงก์ เพื่อนเข้าด้วย LINE แล้วแตะเลือกที่นั่งเอง ใช้ผ่านเบราว์เซอร์ใน LINE ได้

เว็บจริง: https://van-seat-booking.vercel.app/ · โฮสต์บน Vercel · เก็บข้อมูลใน Upstash Redis · ไม่มีขั้นตอน build

## ไฟล์

|---|---|

## ติดตั้งบน Vercel

1. vercel.com → Add New → Project → import repo นี้ · Framework Preset = **Other** · Build Command ว่างไว้
2. Storage → เพิ่ม **Upstash for Redis** แล้วเชื่อมเข้าโปรเจกต์ (ระบบใส่ `KV_REST_API_URL` / `KV_REST_API_TOKEN` ให้ อ่านได้แม้มี prefix เช่น `VAN_SEAT_BOOKING_`)
3. Environment Variables (Production):
   - `LINE_CHANNEL_ID`, `LINE_CHANNEL_SECRET` (จาก LINE Developers → LINE Login channel)
   - ไม่บังคับ: `LINE_REDIRECT_URI` (ถ้าไม่ใส่ใช้ `https://<โดเมน>/api/auth`), `OWNER_KEY` (ยาว 16 ตัวขึ้นไป สำหรับหน้า `/owner`)
4. LINE Developers:
   - Callback URL: `https://<โดเมน>/api/auth` (ใส่ได้หลายบรรทัด เช่น โดเมนพรีวิวและโดเมนจริง)
   - Privacy policy URL: `https://<โดเมน>/privacy`
   - สถานะ channel ต้องเป็น **Published** ถึงจะให้คนอื่นล็อกอินได้
5. Redeploy ทุกครั้งที่เปลี่ยนตัวแปร (ค่าใหม่มีผลกับ deploy ใหม่เท่านั้น)

## การทำงานหลัก

**ผู้จัด**
- สร้างทริป: ชื่อ ผู้จัด วันที่ไป–กลับ เวลาออก จุดนัด จำนวนรถ (ป้ายชื่อ/ทะเบียน) จำนวนที่นั่งสูงสุดต่อคน (ค่าเริ่มต้น 4, เลือก 1–10 หรือไม่จำกัด; ผู้จัดไม่ถูกจำกัด)
- รายชื่อผู้จอง: คัดลอกรายชื่อไปวางในกลุ่ม, แก้ชื่อ, ย้ายที่นั่ง/คัน (เลือกที่นั่งที่มีคน = สลับ), ยกเลิกให้
- เช็กชื่อขึ้นรถเป็นรอบ (ขาไป ขากลับ จุดแวะ) ดูประวัติรอบย้อนหลัง คัดลอกรายชื่อคนที่ยังไม่มา
- ปิดรับจองเอง หรือตั้งเวลาปิดอัตโนมัติ (ระหว่างปิด ผู้จองจอง/ยกเลิกเองไม่ได้ ผู้จัดยังจัดการได้)
- ผู้ช่วยจัดทริปสูงสุด 2 คน ผ่านลิงก์เชิญ `/mytrips?join=<รหัส>` (ใช้ได้ 7 วัน) · ผู้ช่วยแก้ทริปและจัดการที่นั่งได้ แต่ลบทริป เชิญ หรือนำผู้ช่วยออกไม่ได้ · เจ้าของโอนทริปให้ผู้ช่วยได้
- สร้างทริปซ้ำจากทริปเดิม

**ผู้จอง**
- ต้องเข้าด้วย LINE ก่อนจอง (ดูผังได้โดยไม่ต้องล็อกอิน) · ชื่อบนผังพิมพ์เอง: ไทย/อังกฤษ ไม่เกิน 16 ตัว ครั้งต่อไประบบใส่ชื่อล่าสุดให้ (จำในเครื่อง ลืมเมื่อออกจากระบบ)
- ระหว่างล็อกอิน ระบบกันที่นั่งไว้ 5 นาที
- ยกเลิกหรือแก้ชื่อได้เฉพาะที่นั่งของตัวเอง · มีรูปบัตรที่นั่งไว้บันทึก/แชร์
- แจ้งเตือนในหน้าเว็บ (กระดิ่ง) เมื่อผู้จัดเปลี่ยนรายละเอียดทริป ย้าย/ยกเลิก/แก้ชื่อที่นั่งของเรา ลบคันรถ หรือลบทริป
- "ลบข้อมูลของฉัน" (เมนูบัญชีใน `/mytrips`): ยกเลิกที่นั่งในทริปที่ยังไม่ถึง, ทริปที่จบแล้วเก็บชื่อไว้แต่ตัดบัญชีออก, ทริปที่สร้างเลือกลบหรือเก็บ (มีผู้ช่วย = โอนให้ผู้ช่วยคนแรก), ออกจากระบบทุกเครื่อง

**ความถูกต้องเมื่อกดพร้อมกัน**
- จองที่นั่งเดียวกันพร้อมกัน ได้คนแรกคนเดียว (`HSETNX`)
- ติ๊กขึ้นรถ แก้ชื่อ ย้าย/สลับ และเริ่มรอบเช็กชื่อใหม่ เขียนแบบตรวจก่อนเขียนในคำสั่งเดียว (Lua `hcas` ใน `api/_lib.js`) ที่นั่งที่ถูกยกเลิกระหว่างนั้นจะไม่กลับมา และการย้ายไม่ค้างครึ่งทาง

**จำกัดความถี่**
- จอง/ยกเลิก/แก้ 30 ครั้งต่อ 10 นาทีต่อคนต่อทริป (ติ๊กขึ้นรถแยกโควตา 400 ครั้ง) · สร้างทริป 30 ทริปต่อเดือนต่อบัญชี

## ข้อมูลที่เก็บ (Upstash Redis)

| คีย์ | เนื้อหา |
|---|---|
| `trip:<รหัส>` | รายละเอียดทริป เจ้าของ ผู้ช่วย ลิงก์เชิญ รอบเช็กชื่อ (JSON) |
| `seats:<ทริป>:<คัน>` | hash ที่นั่ง → `{name, at, u (บัญชีผู้จอง), c (เวลาขึ้นรถ), cb (ผู้ติ๊ก)}` |
| `log:<ทริป>` | ประวัติทริป 200 รายการล่าสุด |
| `sess:<id>`, `usess:<บัญชี>` | การเข้าสู่ระบบ (30 วัน) และรายการเครื่องของบัญชี |
| `mytrips:<บัญชี>`, `myseats:<บัญชี>` | ดัชนีทริปและที่นั่งของฉัน |
| `inbox:<บัญชี>` (+ `inboxr` `inboxa` `inboxv`) | การแจ้งเตือน 50 รายการ เก็บ 60 วัน |
| `rl:*`, `hold:*`, `mark:*` | ตัวนับจำกัดความถี่, การกันที่นั่งชั่วคราว, รหัสไฮไลต์บัตรที่นั่ง (ทั้งหมดหมดอายุเอง) |

ข้อมูลทริป (ทริป ที่นั่ง ประวัติ) หมดอายุเอง 60 วันหลังวันสุดท้ายของทริป (สิ้นวันเวลาไทย; ตั้งที่ `RETENTION_DAYS`) · ทริปที่ไม่มีวันที่ไม่หมดอายุ (ลบได้ที่ `/mytrips` หรือ `/owner`)

## แพ็กเกจและการชำระเงิน

คนจัดทริปเป็นคนจ่าย ผู้จองที่นั่งใช้ฟรีเสมอ (`api/_plans.js`, `api/pay.js`, หน้า `/plans`)

| | Free | Standard | Premium | ตั๋วรายทริป |
|---|---|---|---|---|
| ราคา | 0 | 149฿/30 วัน · 1,490฿/ปี | 399฿/30 วัน · 3,990฿/ปี | 39฿/ทริป |
| สร้างทริปต่อเดือน | 2 | 20 | ไม่จำกัด (เพดาน 100) | ไม่นับรวม |
| รถต่อทริป | 1 | 5 | 10 | 5 |
| ผู้ช่วยจัด | 0 | 2 | 5 | 2 |
| เช็กชื่อขึ้นรถ | 1 รอบ | ไม่จำกัด | ไม่จำกัด | ไม่จำกัด |

- ทุกอย่างเป็นการจ่ายครั้งเดียว (PromptPay ตัดเงินอัตโนมัติไม่ได้) ซื้อซ้ำ = ต่อเวลา, ใกล้หมดอายุ 3 วันมีแจ้งเตือนในกระดิ่ง
- สิทธิ์ของทริปตามแพ็กเกจของ **เจ้าของทริป** ผู้ช่วยใช้สิทธิ์ของเจ้าของ
- นับทริปตามเดือน (`quota:<YYYY-MM>:u:<uid>`) ลบทริปหรือ "ลบข้อมูลของฉัน" ไม่คืนโควตา ยกเว้นทริปที่ลบภายใน 24 ชม. หลังสร้างและยังไม่มีใครจอง
- บัญชีที่มีทริปอยู่แล้วตอนเปิดขาย ได้ Standard ฟรี 90 วัน (ครั้งเดียว)
- ชำระผ่าน Stripe Checkout (PromptPay หรือบัตร) ลูกค้าเห็นผู้รับเงินเป็น STRIPE PAYMENTS (THAILAND) LTD ไม่ใช่บัญชีส่วนตัว
- หน้า `/owner` มีรายรับ รายการซื้อ และให้สิทธิ์ด้วยมือ (ใส่รหัสทริป → ให้สิทธิ์เจ้าของทริปนั้น)

ตั้งค่าบน Vercel:

| ตัวแปร | ค่า |
|---|---|
| `PLANS_ON` | ไม่ต้องตั้ง = เปิดขาย · `0` = ปิดแพ็กเกจ (ยังเปิดให้บัญชีทดสอบจากหน้า /owner ได้) |
| `STRIPE_SECRET_KEY` | `sk_test_...` หรือ `sk_live_...` จาก Stripe Dashboard → Developers → API keys |
| `STRIPE_WEBHOOK_SECRET` | `whsec_...` จาก webhook ที่ชี้ไป `https://<โดเมน>/api/pay?hook=1` เลือก event `checkout.session.completed` และ `checkout.session.async_payment_succeeded` |

ใน Stripe Dashboard ต้องเปิด PromptPay ที่ Settings → Payment methods ด้วย · ในเครื่อง (dev.js) ไม่ต้องมี Stripe: หน้าชำระเงินมีปุ่ม "จำลองว่าจ่ายแล้ว" · ชุดเทสเดิมรันโดยปิดแพ็กเกจ (`PLANS_ON=0`)

## ความปลอดภัย

- LINE Login แบบเว็บ (ไม่ใช้ LIFF) ขอแค่ `openid profile` · ตรวจ state/nonce และให้ LINE ตรวจ ID token · คุกกี้ `HttpOnly; Secure; SameSite=Lax`
- รหัสบัญชี LINE ไม่ถูกส่งให้ผู้จองคนอื่น · เวลาขึ้นรถและรอบเช็กชื่อเห็นเฉพาะทีมผู้จัด
- Header: `X-Frame-Options: DENY`, `frame-ancestors 'none'`, `nosniff` ทุกหน้า · ให้ Google เก็บแค่หน้าแรกกับ `/privacy` (หน้าอื่นและ `/api` เป็น `noindex, nofollow` + `robots.txt`) · ชื่อจองห้ามใช้คำสงวน (admin, staff, คนขับ ฯลฯ)
- หน้า `/owner` ต้องมี `OWNER_KEY` (ไม่ตั้ง = API ตอบ 404) เปิดด้วย `/owner#คีย์` แล้วคีย์ถูกลบออกจากแถบ URL ทันที

## รันในเครื่อง

```
node dev.js
```

เปิด http://localhost:8765 ใช้กติกา rewrite เดียวกับ `vercel.json` และรัน `api/*.js` จริงกับ Redis จำลองในหน่วยความจำ (ข้อมูลหายเมื่อปิด) ไม่ต้องมีบัญชีใด ๆ ต้องมี Node 18 ขึ้นไป

- ล็อกอินจำลองแทน LINE: `/api/auth?start=1&as=ชื่อ&r=/mytrips`
- หน้า owner: `OWNER_KEY=คีย์ยาว16ตัวขึ้นไป node dev.js`
