# van-seat-booking

เว็บจองที่นั่งรถตู้ 10 ที่นั่ง แตะที่นั่งในผัง ใส่ชื่อ แล้วกด OK ทุกคนที่เปิดลิงก์เห็นรายชื่อชุดเดียวกัน ไม่ต้องล็อกอิน ใช้เปิดผ่านไลน์ได้

- `index.html` หน้าแรก `/` (แนะนำ เลือกทางผู้จัด/ผู้จอง ช่องใส่รหัสทริป)
- `book.html` หน้าจองที่นั่ง (ไฟล์เดียว ไม่ต้อง build)
- `trips.html` หน้าสร้าง/แก้ไขทริป (ชื่อทริป เพจ วันที่ เวลารถออก นัดพบ จำนวนรถ)
- `api/seats.js` จองและยกเลิกที่นั่ง, `api/trip.js` สร้าง/แก้ทริป, `api/_lib.js` ตัวช่วยร่วม (เก็บข้อมูลลง Upstash Redis)

## หลายทริป หลายคัน

- เข้าด้วย LINE แล้วเปิด `/trips/new` กรอกรายละเอียด เลือกจำนวนรถ แล้วกดสร้าง ได้ลิงก์ผู้จอง `/รหัสทริป` (8 ตัว) ส่งเข้ากลุ่ม
  - ทริปผูกกับบัญชี LINE ที่สร้าง ดู แก้ (`/trips#รหัสทริป-o`) และลบได้เฉพาะบัญชีนั้น จากหน้า `/mytrips` ได้ทุกเครื่อง
  - สร้างได้ 30 ทริปต่อเดือนต่อบัญชี
- ข้อมูลเก่าไม่หาย (เป็นทริป `default` คัน A) แต่ `/` ที่ไม่มี `?t=` ตอนนี้เป็นหน้าแรก ลิงก์เดิมเปิดได้ที่ `/?t=default`

## วิธีติดตั้ง

1. เข้า vercel.com → Add New → Project → import repo นี้ ตั้ง Framework Preset เป็น **Other** ปล่อย Build Command ว่างไว้
2. ในโปรเจกต์ ไปที่ Storage → เพิ่ม **Upstash for Redis** แล้วเชื่อมเข้ากับโปรเจกต์ ระบบจะใส่ตัวแปร `KV_REST_API_URL` และ `KV_REST_API_TOKEN` ให้เอง (ถ้ากำหนด prefix ไว้ เช่น `VAN_SEAT_BOOKING_` ก็อ่านได้)
3. กด Redeploy เพื่อให้ตัวแปรมีผล

## วิธีใช้

- แตะที่นั่งว่าง → ใส่ชื่อเล่น (ไทย/อังกฤษ ไม่เกิน 16 ตัว ไม่มีช่องว่าง ตัวเลข หรือสัญลักษณ์ และต้องมีตัวอักษรอย่างน้อย 1 ตัว) → "จองที่นั่ง"
- แตะที่นั่งของตัวเอง → "แก้ชื่อ" หรือ "ยกเลิกการจอง" → "ยืนยันยกเลิก" (ยกเลิกได้เฉพาะคนจองหรือคนจัดทริป)
- ที่นั่งของตัวเองเป็นสีเขียวน้ำเงิน (ตามบัญชี LINE ทุกเครื่อง)
- ผังอัปเดตเองทุก 8 วินาทีขณะเปิดหน้า
- เปิดได้ทุกเบราว์เซอร์ (มือถือ/คอม) · ใน LINE เข้าสู่ระบบอัตโนมัติ

## ข้อมูลที่เก็บ

ทริป: `trip:<รหัส>` (JSON). ชื่อผู้จองและเวลาจอง: hash `seats:<ทริป>:<คัน>` (ทริปเดิมคัน A ยังใช้ `van:seats`)

เดิมเก็บใน Redis hash `van:seats` สองคนกดที่นั่งเดียวกันพร้อมกัน ระบบรับคนแรกคนเดียว (`HSETNX`)

## รันในเครื่อง (ไม่ต้อง deploy)

```
node dev.js
```

เปิด http://localhost:8765 ใช้กติกา rewrite เดียวกับ `vercel.json` (`/`, `/trips`, `/<รหัสทริป>`) และรัน `api/*.js` จริงกับฐานข้อมูลจำลองในหน่วยความจำ (ข้อมูลหายเมื่อปิดเซิร์ฟเวอร์) ไม่ต้องมีบัญชี Upstash ต้องมี Node 18 ขึ้นไป อย่าใช้ `python3 -m http.server` เพราะไม่รู้จัก `/a` จะขึ้น 404

## หน้า Owner (ผู้พัฒนา)
- `/owner` ดูทุกทริปและลบทริปได้ ต้องตั้ง environment variable `OWNER_KEY` (อย่างน้อย 16 ตัวอักษร) ใน Vercel แล้ว redeploy ถ้าไม่ตั้ง หน้านี้ใช้ไม่ได้ (API ตอบ 404)
- เปิดครั้งแรกด้วย `/owner#คีย์` (คีย์ไม่ถูกส่งไปกับ URL ฝั่งเซิร์ฟเวอร์ และถูกลบออกจากแถบ URL ทันที) หรือพิมพ์ในช่องที่หน้าเว็บ
- ทดสอบในเครื่อง: `OWNER_KEY=คีย์ยาว16ตัวขึ้นไป node dev.js`

## ลบข้อมูลอัตโนมัติหลังทริปจบ
- ข้อมูลของทริป (ทริป การจอง ประวัติ) หมดอายุเอง 60 วันหลังวันสิ้นสุดทริป (ใช้ endDate ถ้าไม่มีใช้ startDate; ตัดที่สิ้นวันเวลาไทย) ตั้งค่าที่ `RETENTION_DAYS` ใน `api/_lib.js`
- ทริปที่ไม่มีวันที่ และทริป default จะไม่หมดอายุ
- ทริปที่สร้างก่อนฟีเจอร์นี้: ใน `/owner` กดปุ่ม "ตั้งวันลบอัตโนมัติให้ทุกทริป" ครั้งเดียว (ทริปที่เลยกำหนดไปแล้วจะได้เวลาอีก 7 วันก่อนถูกลบ)

## เข้าสู่ระบบด้วย LINE (branch `line-login`)

- เข้าสู่ระบบด้วย LINE Login แบบเว็บ (ไม่ใช้ LIFF) ขอสิทธิ์แค่ `openid profile` เก็บรหัสผู้ใช้ LINE ชื่อ และรูปโปรไฟล์ ไม่เก็บอีเมล/เบอร์โทร
- หน้า `/mytrips` = "ทริปของฉัน" (คนจัด) + "ที่นั่งของฉัน" (คนจอง) ใช้ได้ทุกเครื่อง
- ต้องเข้าด้วย LINE ก่อนจอง ยกเลิก และสร้างทริป (ดูผังได้โดยไม่ต้องเข้าสู่ระบบ) · ที่นั่งยกเลิกได้เฉพาะคนจองหรือคนจัดทริป
- จำกัดการจอง/ยกเลิก 30 ครั้งต่อ 10 นาทีต่อคนต่อทริป และสร้างทริปได้ 30 ทริปต่อเดือนต่อบัญชี (นับตามเวลาไทย)
- ตัวแปรใน Vercel: `LINE_CHANNEL_ID`, `LINE_CHANNEL_SECRET` (ไม่บังคับ: `LINE_REDIRECT_URI`, ถ้าไม่ใส่ใช้ `https://<โดเมน>/api/auth`) · `VSB_REQUIRE_LOGIN=0` = กลับไปให้จอง/สร้างทริปได้โดยไม่เข้าสู่ระบบ
- Callback URL ใน LINE Developers: `https://<โดเมน>/api/auth` (ใส่ได้หลายบรรทัด เช่น โดเมนพรีวิวของ branch และโดเมนจริง)
- รันในเครื่อง (`node dev.js`) ใช้บัญชีจำลองแทน LINE: `/api/auth?start=1&as=ชื่อ&r=/mytrips`
- จำกัดที่นั่งต่อคนต่อทริป (รวมทุกคัน) ค่าเริ่มต้น 4 ที่ คนจัดทริปเลือกได้ในฟอร์ม (1–10 หรือไม่จำกัด) · คนจัดทริปไม่ถูกจำกัด
- หน้า `/privacy` = นโยบายความเป็นส่วนตัว (ใส่ลิงก์นี้ใน LINE Developers → Basic settings → Privacy policy URL)
- "ลบข้อมูลของฉัน" ในหน้า `/mytrips`: ยกเลิกที่นั่งในทริปที่ยังไม่ถึง, ทริปที่จบแล้วเก็บชื่อไว้แต่ตัดรหัส LINE ออก, ทริปที่สร้างเลือกลบหรือเก็บไว้ (ไม่มีเจ้าของ แก้ไม่ได้อีก ลบตัวเองตามวันหมดอายุ), ลบรหัส LINE ออกจาก log, ออกจากระบบทุกเครื่อง
- คนจัดทริป: หน้า `/mytrips` → "รายชื่อผู้จอง · จัดการที่นั่ง" ดูรายชื่อทุกคัน แก้ชื่อ ย้ายที่นั่ง/คัน (เลือกที่นั่งที่มีคน = สลับกัน) และยกเลิกให้ได้ · ผู้จองแก้ชื่อบนที่นั่งของตัวเองได้ในหน้าผัง
- ไม่มี Admin Pass / ลิงก์แก้ไขลับแล้ว (ลบออกพร้อมระบบย้ายข้อมูลเก่าเข้าบัญชี หลังล้างฐานข้อมูล)
